# TestLookup logo files

The mark is the bracketed wordmark `[testlookup]`: blue brackets in JetBrains Mono, "test" in regular and "lookup" in bold Inter. The app draws it in `frontend/src/components/ui/AppLogo.tsx`, and the live-text originals are in `frontend/src/assets/brand/`.

The files here are the same mark converted to paths, so they look the same in places that cannot load web fonts, such as a README on GitHub or a social card. They are the outlined copies the website uses.

| File | Use on |
|---|---|
| `wordmark-dark.svg` | Dark backgrounds (blue `#4493f8`, white text) |
| `wordmark-light.svg` | Light backgrounds (blue `#2563eb`, near-black text) |
| `glyph-dark.svg` | The square `[t]` glyph, on dark backgrounds |

Keep the proportions, keep the logo at least 24 px tall, and leave clear space of at least a quarter of its height around it.

The older black-pill logo (`testLookup_Logo.png`) was retired when the app moved to this mark; it is no longer in the repository.
