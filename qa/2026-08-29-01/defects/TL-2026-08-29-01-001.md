# TL-2026-08-29-01-001 — Dashboard readiness card collapses beside workflow ribbon

- Reported by: EX exploratory browser sweep
- Confirmed by: TR independent reproduction before fix
- Severity: S4 (cosmetic/minor UX degradation)
- Priority: P2
- Component/surface: `frontend/src/pages/OverviewPage.tsx`, Dashboard top row at desktop width
- Status: VERIFIED_FIXED in homelab image `build-20260829-050941`

## Reproduction

1. Sign in to the homelab dashboard.
2. Use a 1280px-wide browser viewport.
3. Open `/overview` with either `All Projects` or `Payment Service` selected.
4. Inspect the release-readiness card beside the Quality workflow card.

Expected: the two cards share the row according to the intended `1fr / 1.55fr` ratio, with readable readiness copy.

Observed before fix: computed tracks were `154px / 800px`; the readiness content column and lede measured `0px` wide, so the headline and explanatory copy wrapped vertically one word at a time.

## Triage and review

The defect reproduced deterministically in both project scopes. Source inspection identified intrinsic minimum sizing from the horizontally scrollable workflow ribbon as the cause. Existing component tests covered content/state rendering but not desktop geometry, so they did not catch the defect. No data, auth, API, or persistence impact was found.

## Fix

The top-row grid now uses `minmax(0,1fr)` and `minmax(0,1.55fr)`. The workflow ribbon retains its own `overflow-x-auto` behavior, so the fix removes intrinsic track pressure without changing the intended small-screen single-column layout.
