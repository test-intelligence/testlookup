# TL-2026-09-18-01-010 — Enhancement: put the AI report above Agent Stages on `/agents`, and make Stages collapsible

- Requested by: **user**, 2026-09-18
- Type: **Enhancement** (not a defect)
- Priority: P2
- Component/surface: `frontend/src/pages/AgentStatusPage.tsx`
- Status: **BACKLOG — not implemented**

## Request

1. The report section that shows the summary should be at the **top** of the
   page; "Agent Stages" should sit **below** it.
2. "Agent Stages" should have an **expand / collapse** control.

## Why it is worth doing

The report is the pipeline's headline output — the page's own code already says
so, in the comment explaining why the report defaults to expanded:

> The AI report is shown by default (expanded) once a pipeline is selected — it's
> the headline output of the pipeline, so users shouldn't have to click "View AI
> report" to see it.

The layout does not match that reasoning: the headline output currently sits
below the stage detail, so the reader scrolls past the mechanism to reach the
conclusion. Collapsing Stages makes the ordering usable on a laptop rather than
merely reordered.

## Notes for whoever picks it up

- `showSummary` already exists and defaults to `true`, so the report's
  expand/collapse state is established; Agent Stages needs the equivalent.
- Keep the report expanded-by-default behaviour — it is deliberate and is pinned
  by `AgentStatusPage.test.tsx` ("shows the AI report by default (expanded) once
  a pipeline is selected"). A reorder must not regress it.
- Collapse state is a per-viewer convenience, so `localStorage` is appropriate —
  wrapped in try/catch, since a blocked-storage browser must still render.
- This touches a page with an open fix in this same program
  (TL-2026-09-18-01-009, run-switch reset). Land that first to keep the diffs
  separable.

## Tests required

- The report renders above the stages in DOM order (assert relative position,
  not just presence).
- Agent Stages collapses and re-expands, and the collapsed state does not hide
  the report.
- The existing expanded-by-default report assertion still passes.
